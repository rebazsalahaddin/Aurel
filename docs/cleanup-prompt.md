- Cleaner project organization.

==================================================
PROJECT STRUCTURE CLEANUP
==================================================

Review the entire project folder structure.

Tasks:

1. Analyze every file and folder.
2. Identify:
   - Active files.
   - Required resources.
   - Duplicate files.
   - Unused files.
   - Old experiments.
   - Temporary files.
   - Abandoned implementations.
   - Development leftovers.

IMPORTANT:
Do NOT delete anything unless you are 100% certain it is completely unnecessary.

If a file/folder does not directly contribute to the current app functionality:

- Do NOT delete it immediately.
- Create an appropriate archive/backup folder.
- Move it there safely.

Examples:
- Deprecated code.
- Old prototypes.
- Previous experiments.
- Unused assets.
- Temporary resources.

The goal is a clean project without losing historical work.
