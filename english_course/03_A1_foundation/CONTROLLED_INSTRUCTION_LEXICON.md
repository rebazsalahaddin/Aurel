# Controlled-Instruction Lexicon

Rule: every learner-facing prompt uses only words demonstrated before use, in this staged order. Instructions can never be harder than the target. Icons + demo animations carry meaning on first exposure; the word then attaches to the demonstrated action.

## Stage 1 (Chapter 1, Lesson 1 — demonstrated in first-run orientation)

`listen` (ear icon + play demo) · `look` (eye icon) · `tap` (finger icon + animation) · `choose` (hand selecting one of three) · `match` (two items connecting) · `say` (mouth icon + speak demo) · `repeat` (loop arrow + replay demo)

## Stage 2 (from Chapter 1, Lesson 2)

`one` · `two` · `again` · `correct` (green check + gentle chime) · `try again` (soft arrow, never red X shame framing)

## Stage 3 (from Chapter 2, Lesson 1)

`put in order` (numbered tiles sliding) · `first` · `next` · `last`

## Stage 4 (from Chapter 3, Lesson 2)

`read` · `answer` · `record` (microphone + counting pulse) · `play` · `check`

## Audit rule

Every new practice/quiz item declares its instruction words; the lens 13 check verifies each is in the permitted stage for that lesson. Any instruction word outside the current stage must be replaced by an icon + demonstrated behaviour, or delayed.
